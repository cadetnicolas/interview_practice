# 信贷风控题库（含答案锚点）

按层级分档。`必答` 是命中即得分的最低要求，`加分` 是资深信号，`陷阱` 是高频扣分点。
出题时优先选与用户简历/目标岗位匹配的题目，不要按顺序平推。

---

## L1 · 基础概念（0-3 年）

**R101｜KS、AUC、IV 有什么区别，各自什么时候用？**
- 必答：KS 衡量好坏样本累计分布的最大间隔，看尾部区分力；AUC 衡量全局排序能力，与阈值无关；IV 是单变量对目标的信息量，用于变量筛选。三者不可互替。
- 加分：KS 对中间客群不敏感、受通过率影响；AUC 在极度不平衡时依然稳定但对业务成本不敏感；IV 与 WOE 同源，IV 高不代表方向正确。
- 陷阱：说"AUC 高就是好模型"，不谈业务口径与通过率约束。

**R102｜为什么评分卡普遍用 WOE 编码而不是 one-hot？**
- 必答：WOE 把类别/分箱映射到对数几率，天然处理非线性与单调性；缺失值可单独成箱而不丢信息；系数解释为"每个 WOE 单位对 odds 的影响"，业务可读。
- 加分：WOE 要求分箱与目标同向，需检查单调性；WOE 是样本内统计量，跨期稳定性差时要重新校准；IV 用于筛箱。
- 陷阱：只说"WOE 能处理缺失"，说不出与 logistic 的 odds 关系。

**R103｜PSI 怎么算？为什么阈值取 0.1 / 0.25？**
- 必答：按分箱比较基准期与当前期的占比，`PSI = Σ (实际占比 - 期望占比) × ln(实际/期望)`。0.1 以下视为稳定，0.1–0.25 需关注，0.25 以上显著漂移。
- 加分：阈值是行业经验值不是统计检验，需结合样本量；PSI 对分箱方式敏感；PSI 只反映分布变化，不反映区分力变化，要配 KS/AUC 一起看。
- 陷阱：把 PSI 当作"模型好坏"指标；分母出现 0 时不处理。

**R104｜评分卡为什么很少直接上深度学习？**
- 必答：监管要求可解释（拒贷需给出理由）；样本量有限、坏样本更少，深度模型易过拟合；评分卡稳定、易监控、易迭代；上线与审计成本低。
- 加分：并非绝对——大流量平台会用 GBDT/深度学习提升区分度，再用 SHAP/代理模型做解释；关键在"能否解释到单个拒绝原因"。
- 陷阱：把"可解释性"说成"领导看不懂"。

**R105｜坏样本只占 3%，怎么处理样本不平衡？**
- 必答：优先调整样本权重或做分层抽样（保留全部坏样本、下采样好样本），而不是简单 SMOTE；评估指标用 KS/AUC/提升度而非准确率；最终校准回真实先验，否则概率不可用。
- 加分：过采样会破坏概率校准，需做先验修正；分箱与 WOE 应在采样前或按原始分布计算。
- 陷阱：无脑 SMOTE 后又直接用输出概率做定价。

**R106｜变量筛选的完整流程是什么？**
- 必答：业务可解释性初筛 → 缺失率/集中度过滤 → IV 排序 → 相关性/共线性（VIF、相关系数矩阵）→ 逐步回归或 LASSO → 系数符号与业务方向一致性检查 → 稳定性（跨期 IV）。
- 加分：符号为负要能解释（如"征信查询次数多反而好"可能是已获批人群的选择效应）；筛掉变量要留痕，便于复盘。
- 陷阱：只按 IV 排序取前 20 个。

**R107｜评分卡怎么刻度化？PDO 是什么？**
- 必答：`Score = A - B × ln(odds)`，用基准分与 PDO（odds 翻倍所需分数）解出 A、B。PDO 越小分数对风险越敏感。
- 加分：刻度化让不同模型的分数可比、可跨版本迁移；分数段与风险等级、cutoff 直接挂钩。
- 陷阱：刻度化后仍用原始概率谈 cutoff。

**R108｜缺失值怎么处理？**
- 必答：先判断缺失机制——完全随机、随机、还是与风险相关（如无征信记录=薄文件客群）。相关缺失要单独成箱或建缺失指示变量，不能简单填均值。
- 加分：缺失本身常是强信号（"没借过钱"和"借了不还"是两类人）；填充会抹掉这个信号。
- 陷阱：统一用中位数填充。

**R109｜分箱为什么要保证单调性？**
- 必答：单调保证风险随变量值单向变化，业务可解释、外推稳定；非单调分箱多为样本噪声，跨期易翻转。
- 加分：卡方分箱/决策树分箱后要人工合并违反单调的箱；允许 U 型但要能给出业务解释。
- 陷阱：为了 IV 最大化保留锯齿状分箱。

## L2 · 进阶实战（3-5 年）

**R201｜坏样本怎么定义？表现期怎么定？**
- 必答：常见口径 DPD30+/60+/90+，需明确"首次达到"还是"观察窗内曾达到"；表现期要覆盖到风险充分暴露（如 12 期），并与业务回收周期匹配。
- 加分：口径变化会让历史模型不可比，必须版本化；M1→M4 迁徙率可反推表现期是否足够。
- 陷阱：用 DPD1 当坏样本（噪音大、可回收）。

**R202｜样本没成熟怎么办？**
- 必答：只有表现期足够的样本才能打坏标签；未成熟样本只能作好样本使用是错的（会低估风险）。可选做法：缩短表现期并接受口径变化、只用成熟月份建模、或对未成熟样本做加权/推断。
- 加分：明确说出"未成熟不等于好"，并给出成熟度检查（各月龄坏账率是否收敛）。
- 陷阱：把"至今未逾期"直接标 0。

**R203｜拒绝推断有必要吗？怎么做？**
- 必答：有必要——模型只在获批人群上训练，直接外推到全量会产生选择偏差。方法：打包法（把拒绝样本按高分好/低分坏赋予硬标签）、模糊增广、两阶段（先建通过模型再校正）、以及利用被拒后在他行表现的外部数据。
- 加分：拒绝推断会引入假设，需评估敏感度；若通过率很高（>70%）偏差可接受，可跳过。
- 陷阱：认为"用全量申请数据就能解决"。

**R204｜为什么验证必须用 OOT 而不是随机切分？**
- 必答：随机切分让同期样本同时进训练和验证，时间信息泄露，指标虚高；OOT 用未来时段验证，才反映上线后的真实表现。
- 加分：OOT 还能暴露客群漂移与策略变更的影响；理想是三段——训练/时间外验证/最新监控。
- 陷阱：只报随机切分的 AUC。

**R205｜模型上线后监控哪些指标？**
- 必答：区分力（KS/AUC 月度）、稳定性（分数 PSI、变量 PSI）、排序稳定性（分位坏账率是否单调）、校准（预测 PD vs 实际坏账）、业务指标（通过率、坏账率、额度使用率）。
- 加分：设预警阈值与处置动作（观察/重训/降级）；监控要区分"数据问题"和"真实风险变化"。
- 陷阱：只监控 PSI。

**R206｜cutoff 怎么定？**
- 必答：不是单看坏账率，而是通过率—坏账率—利润的权衡。做法：按分数段出决策表，算每个 cutoff 下的通过率、预期坏账率、边际坏账率、单位利润，找业务可接受的最优区间。
- 加分：边际分析——每放宽一分带来的新增通过人群坏账率是否仍低于盈亏平衡线；还要看 Swap Set 里被换进换出的是谁。
- 陷阱：直接取 KS 最大点当 cutoff（KS 点与利润最优点通常不重合）。

**R207｜什么是 Swap Set（置换集）分析？**
- 必答：比较新旧模型/策略在同一 cutoff 下，被新模型"换进来"和"换出去"的人群，分别看两组的坏账率与规模，判断改动是净收益还是只是挪动。
- 加分：调入集坏账率是关键——如果调入人群坏账率高于整体，说明放宽没带来增量；同时要评估对存量客户体验的影响。
- 陷阱：只报整体通过率与坏账率的变化，不做人群拆解。

**R208｜Vintage 和迁徙率怎么用？**
- 必答：Vintage 按放款月份对齐账龄，看不同批次同账龄的坏账率，识别"是这批客户更差还是账龄还没到"；迁徙率看 M0→M1→M2→M3 的转化，定位恶化发生在哪一环。
- 加分：Vintage 要按客群/渠道/产品拆分，否则辛普森悖论；迁徙率异常要区分是前端准入放松还是催收失效。
- 陷阱：用整体逾期率同比判断风险升降（混淆账龄结构）。

**R209｜额度和定价怎么和风险挂钩？**
- 必答：额度看风险与还款能力（收入负债比、多头），常用风险定价矩阵；定价要覆盖资金成本+风险成本+运营成本+目标利润，可用 RAROC 衡量。
- 加分：高定价会引发逆向选择（好客户不借），需监控价格弹性；额度提额要分批灰度。
- 陷阱：只按分数线性给额度。

**R210｜策略规则怎么挖？怎么防过拟合？**
- 必答：单变量分箱找高风险切点、决策树找组合规则；规则要在 OOT 上验证，样本量设下限（如命中>500 且坏样本>50），避免规则只为少数坏样本服务。
- 加分：规则之间要做重叠分析，避免同一批人被多条规则重复拦截；上线要评估对通过率的冲击。
- 陷阱：在训练集上挖出 30 条规则全部上线。

**R211｜模型和规则的分工边界在哪？**
- 必答：模型处理连续、渐变的风险排序；规则处理硬性政策（年龄、地域禁入）、确定性强的高风险信号（黑名单、司法涉诉）、以及模型覆盖不到的稀疏场景。
- 加分：规则与模型要有主次，避免规则把模型切碎；定期评估规则是否已被模型吸收（增量价值下降就该下线）。
- 陷阱：规则越多越安心。

**R212｜客群要不要分层建模？**
- 必答：看分层后样本量是否支撑、分层是否带来显著区分度提升、分层维度是否稳定可得。常见分层：新客/老客、有征信/薄文件、产品线。
- 加分：分层会带来维护成本与样本稀释，可用"主模型+分层修正"折中。
- 陷阱：为了分层而分层，每层样本不足千条。

**R213｜信用风险和欺诈风险的区别？**
- 必答：信用风险是"有还款意愿但能力不足"，看长期表现、可用评分卡；欺诈是"无还款意愿"，看申请行为、设备、关系网络，要求秒级拦截、样本极少、对抗性强。
- 加分：两套体系的数据、模型、时效、评估指标都不同；欺诈标签滞后且不完整（未遂欺诈无标签）。
- 陷阱：用信用评分卡做反欺诈。

**R214｜冷启动客群（新业务/新产品）怎么建模？**
- 必答：迁移学习（用相近客群模型+校准）、规则先行（业务专家经验）、小额短期限试水积累样本、外部数据/三方分补位。
- 加分：冷启动阶段重点是"控损"而非"精细化"，要用更保守的 cutoff 和更小的额度试错。
- 陷阱：直接套用其他产品模型不做校准。

## L3 · 资深/负责人（5 年以上）

**R301｜从 0 到 1 搭一套风控体系，你的路径是什么？**
- 必答：分四层——数据层（内外部数据接入、指标体系）、模型层（评分卡/策略模型）、策略层（准入、额度、定价、催收）、监控层（指标看板、预警、复盘）。落地顺序：先规则保底 → 再评分卡提效 → 再精细化分层。
- 加分：组织与流程同样重要（审批流、模型风险管理、版本管理、跨部门协同）；先定北极星指标（风险调整后收益），再谈模型。
- 陷阱：一上来就讲模型算法，不谈数据与流程。

**R302｜坏账率降了 30%，怎么证明是你的策略带来的？**
- 必答：做归因拆解——区分宏观环境（行业整体趋势）、客群结构变化（渠道/产品mix）、账龄结构、以及策略本身的组内效应。方法：对照组/AB 实验、shift-share 分解、Swap Set、同口径 Vintage 对比。
- 加分：承认无法完全剥离时，用"策略上线前后同客群对比+同行基准"做三角验证；主动说明归因的置信度。
- 陷阱：直接把同比降幅归功于自己。

**R303｜模型上线要过什么审批？MRM 关注什么？**
- 必答：模型文档（方法、数据、假设、局限）、独立验证（区分力、稳定性、公平性、敏感性）、上线审批、投产后监控、定期复审与退出机制。
- 加分：关注模型风险分级（影响面决定复审频率）、可解释性证据、以及对特定群体的公平性检验。
- 陷阱：认为审批只是走流程。

**R304｜压力测试怎么做？**
- 必答：定义情景（失业率上升、收入下降、利率上行、客群劣变），映射到 PD/LGD/EAD 的冲击，测算资本与拨备缺口；分敏感性测试与情景测试。
- 加分：情景要可解释且与业务变量挂钩（如"失业率+2pct → 逾期率+80bp"），而不是拍一个坏账率乘数。
- 陷阱：只做"坏账率翻倍"的单一情景。

**R305｜团伙欺诈怎么识别？**
- 必答：关系网络（设备、IP、联系人、银行卡、地址的共现）、申请行为时序（集中时间批量申请）、资料相似度（模板化填写）、以及"个体看起来正常但群体异常"的模式。
- 加分：图算法（社区发现、连通分量）、无监督异常检测兜底、以及人工审核闭环沉淀标签。
- 陷阱：只靠单条规则（如同一 IP 多申请）。

**R306｜策略多久迭代一次？怎么管理版本？**
- 必答：监控触发式迭代（PSI/KS 越界、坏账异常）+ 定期迭代（季度/半年）；版本要保留策略快照，保证历史决策可复现。
- 加分：变更要有灰度、回滚方案、以及影响评估（通过率冲击、存量客户影响）。
- 陷阱：频繁小改导致无法归因。

**R307｜客群迁移导致策略失效，怎么发现和应对？**
- 必答：发现靠分群监控（渠道/地域/产品维度的坏账与 PSI 拆解）+ Vintage 对比；应对：重新校准、分层重建、收紧准入、调整额度。
- 加分：区分"客群变了"还是"客群没变但行为变了"，前者调策略，后者查模型与外部环境。
- 陷阱：只做整体监控，不做分群拆解。

**R308｜业务方要求放宽准入冲规模，你怎么处理？**
- 必答：量化代价——用决策表算出放宽后新增人群的预期坏账与利润，给出"可承受的放宽幅度"；提出替代方案（提高定价、降低额度、加强催收、分批灰度）。
- 加分：把争论从"要不要放"转成"以什么价格放"，用风险调整后收益对齐目标；设置止损线与退出机制。
- 陷阱：一味拒绝或一味服从。

## 陷阱题 / 压力题（任何层级都可能被问）

**R401｜IV 很高的变量是不是一定好用？**
- 要点：不一定。可能是信息泄露（用了贷后信息）、可能是时间不稳定、可能与目标同源（如"是否被催收过"直接来自结果）、可能与其他变量高度共线。IV 高只说明样本内区分强。
- 扣分：直接说"IV>0.3 就是强变量，直接用"。

**R402｜模型在某个时段突然失效，你怎么排查？**
- 要点：先分清是数据问题（口径变更、上游断流、特征延迟）、还是客群问题（渠道mix变化）、还是真实风险变化（宏观冲击）。排查顺序：数据质量 → 特征分布 PSI → 分群表现 → 外部环境。
- 扣分：第一反应是"重训模型"。

**R403｜只有 3000 条坏样本，还能建模吗？**
- 要点：能，但要降复杂度——变量数控制在坏样本的 1/10 以内、优先逻辑回归、强正则、分箱粗化、必须有 OOT 验证。结论要给置信区间，不能过度解读。
- 扣分：直接上 GBDT 200 棵树。

**R404｜你的模型上线后效果比测试差很多，为什么？**
- 要点：样本选择偏差（测试集不含拒绝人群）、时间漂移、特征上线实现与离线不一致（特征穿越/口径差异）、策略叠加影响、以及测试集指标乐观（用了未来信息）。
- 扣分：只说"过拟合"。

**R405｜如果让你现在推翻自己之前的方案，你会改哪里？**
- 要点：考的是反思能力。好的回答会指出具体的假设失效点、当时信息不足导致的取舍、以及现在会怎么做。承认局限比嘴硬加分。
- 扣分：说"我的方案没问题"。
