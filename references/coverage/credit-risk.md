# 考点地图：信贷风控

**这不是题目池。** 不要从这里抽题，不要按顺序问。题目一律从候选人的简历和 JD 现场生成（见 `../question-design.md`）。

这份文件只有一个用途：**他答完之后，查这里——这一答落在哪个考点、什么算过线、该往哪追。**

分组与 `roles/credit-risk.md` 的五个维度对应。

---

## 一、数据与证据

### 指标口径与验证方式
**触发**：提到 KS / AUC / IV / "模型效果不错"，但没给样本量和时间窗口
**好回答**：说得出指标在哪个客群、哪段时间、OOT 还是随机切分上测的；知道 KS 看尾部、AUC 看全局、IV 只用于筛选
**假好**：报个 0.42 就完事；说"AUC 高就是好模型"，不谈通过率约束
**追问**：① 基线多少 → ② OOT 还是随机，为什么 → ③ 上线后实际多少

### 坏样本定义与表现期
**触发**：说"坏账率""逾期率"，但没定义口径
**好回答**：明确 DPD30/60/90、是"首次达到"还是"观察窗内曾达到"；表现期覆盖到风险充分暴露，与回收周期匹配
**假好**：用 DPD1 当坏样本；口径变了却不提模型不可比
**追问**：① 为什么用这个 DPD → ② 表现期怎么定的 → ③ 没成熟的样本怎么处理

### 样本不成熟与冷启动
**触发**：数据只有几个月；新业务/新产品要建模
**好回答**：知道"未成熟≠好样本"；做法是缩短表现期接受口径变化、只用成熟月份、或加权推断；冷启动用迁移+校准+规则先行+小额试水
**假好**：把"至今未逾期"直接标 0；直接套用其他产品模型不做校准
**追问**：① 各月龄坏账率收敛了吗 → ② 未成熟样本怎么用 → ③ 冷启动阶段控损还是精细化

## 二、方法与判断

### 变量筛选与可解释性
**触发**：说"选了 XX 个变量""用了 XX 模型"
**好回答**：业务初筛 → 缺失/集中度 → IV → 共线性 → 逐步回归 → 符号方向检查 → 跨期稳定性；符号为负能解释（如查询多次反而好，是选择效应）
**假好**：只按 IV 取前 20；为了 IV 最大化保留锯齿分箱
**追问**：① 这个变量符号是负的怎么解释 → ② 和另一个变量共线怎么处理 → ③ 筛掉的变量留痕了吗

### 分箱与 WOE 的合理性
**触发**：提到 WOE、分箱、IV
**好回答**：WOE 把分箱映射到对数几率，天然处理非线性；要求与目标同向并检查单调性；WOE 是样本内统计量，跨期不稳定要重算
**假好**：只说"WOE 能处理缺失"，说不出与 odds 的关系；保留非单调箱不解释
**追问**：① 为什么要保证单调 → ② 允许 U 型吗，怎么解释 → ③ WOE 跨期漂移怎么办

### 模型选择与深度学习边界
**触发**：说用了 GBDT / XGBoost / 深度学习
**好回答**：能说清代价——可解释性怎么补（SHAP/代理模型）、样本够不够、上线与审计成本；监管要求能解释到单个拒绝原因
**假好**：认为"深度学习效果一定更好"；不谈拒贷理由怎么出
**追问**：① 拒贷理由怎么生成 → ② 过拟合怎么控制 → ③ 如果只能用逻辑回归，你损失多少

### 拒绝推断
**触发**：提到"全量数据建模""拒绝人群"
**好回答**：知道模型只在获批人群上训练会产生选择偏差；方法有打包法、模糊增广、两阶段、外部表现数据；推断本身带假设，要做敏感度
**假好**：认为"用全量申请数据就解决了"；不提通过率很高时偏差可接受
**追问**：① 用了哪种方法 → ② 被拒人群没标签，怎么验证推断是对的 → ③ 通过率 80% 还需要做吗

## 三、业务与权衡

### cutoff 与通过率权衡
**触发**：提到"阈值""准入线""通过率调整"
**好回答**：不是只看坏账率，而是通过率—坏账率—利润的决策表；做边际分析（新增通过人群的坏账率是否低于盈亏平衡线）；知道 KS 最大点不等于利润最优点
**假好**：直接取 KS 最大点；只报一个 cutoff 数字不给权衡过程
**追问**：① 边际坏账率多少 → ② 盈亏平衡线在哪 → ③ 通过率必须提 5 个点你怎么做

### Swap Set 与策略增量
**触发**：说"新模型/新策略效果更好"
**好回答**：比较新旧在同一 cutoff 下被换进/换出的人群，看调入集坏账率是否高于整体；否则只是挪动不是增量
**假好**：只报整体通过率和坏账率变化，不做人群拆解
**追问**：① 调入人群坏账率多少 → ② 换出去的是谁，会不会误伤好客户 → ③ 怎么排除是环境变化

### 额度与定价
**触发**：提到"额度策略""风险定价"
**好回答**：额度看风险与还款能力（收入负债比、多头），用风险定价矩阵；定价覆盖资金+风险+运营成本+目标利润，可用 RAROC；知道高定价引发逆向选择
**假好**：按分数线性给额度；只谈定价不谈客户流失
**追问**：① 提额怎么灰度 → ② 价格弹性怎么监控 → ③ 盈亏平衡点怎么算

### 规则与模型的分工
**触发**：提到"规则引擎""策略规则"
**好回答**：模型处理连续渐变的风险排序；规则处理硬性政策（年龄、地域禁入）、确定性高风险信号（黑名单、涉诉）、模型覆盖不到的稀疏场景；定期评估规则是否已被模型吸收
**假好**：规则越多越安心；规则把模型切碎
**追问**：① 这条规则和模型重叠多少 → ② 上线后通过率冲击多少 → ③ 什么时候该下线一条规则

### 反欺诈与信用风险
**触发**：简历同时提"反欺诈""评分卡"
**好回答**：信用风险是意愿能力问题，看长期表现；欺诈是无还款意愿，看申请行为、设备、关系网络，要秒级拦截、样本极少、对抗性强；两套数据模型指标都不同
**假好**：用信用评分卡做反欺诈；不谈欺诈标签滞后和未遂无标签
**追问**：① 团伙怎么识别 → ② 未遂欺诈没标签怎么办 → ③ 对抗性怎么应对

## 四、归因与复盘

### 坏账率变化的归因
**触发**：说"坏账率下降 X%""策略上线后改善明显"
**好回答**：拆宏观环境、客群结构、账龄结构、策略组内效应；方法用对照组/AB、shift-share 分解、Swap Set、同口径 Vintage；承认无法完全剥离时用三角验证并说明置信度
**假好**：直接把同比降幅归功于自己
**追问**：① 同期大盘什么走势 → ② 客群结构变了吗 → ③ 有多少是你带来的，怎么证明

### 上线后劣化的排查
**触发**：提到"模型监控""效果变差"
**好回答**：先分数据问题（口径变更、上游断流、特征延迟）、客群问题（渠道 mix）、真实风险变化（宏观）；排查顺序：数据质量 → 特征 PSI → 分群表现 → 外部环境
**假好**：第一反应是"重训模型"
**追问**：① 先查哪一步 → ② 怎么区分数据问题和真实劣化 → ③ PSI 超过 0.25 你会做什么

### Vintage 与迁徙率
**触发**：提到"资产质量""逾期率"
**好回答**：Vintage 按放款月对齐账龄看同账龄坏账，识别是客群更差还是账龄没到；迁徙率看 M0→M1→M2 定位恶化环节；要按客群/渠道拆，否则有辛普森悖论
**假好**：用整体逾期率同比判断风险升降（混淆账龄结构）
**追问**：① 这个批次更差还是账龄没到 → ② 恶化发生在哪一环 → ③ 分群拆了吗

### 从 0 到 1 搭体系
**触发**：职级偏高，或简历写"从 0 搭建"
**好回答**：四层——数据、模型、策略、监控；落地顺序是先规则保底→评分卡提效→精细化分层；组织与流程同样重要（审批流、模型风险管理、版本管理）；先定北极星指标（风险调整后收益）
**假好**：一上来讲算法，不谈数据与流程
**追问**：① 第一步做什么 → ② 什么时候才上模型 → ③ 团队怎么配

## 五、合规与边界

### 拒贷理由与可解释
**触发**：牵涉到模型上线、监管、审计
**好回答**：拒贷理由要能映射到标准原因码或具体规则；输出不能是自由文本；模型变更走审批，留版本快照保证历史决策可复现
**假好**：认为"模型有 SHAP 就够了"；说不清监管问起怎么答
**追问**：① 这个客户为什么被拒，你能指到哪 → ② 模型换版本后历史决策怎么复现 → ③ 监管问起你怎么答

### 业务方压通过率
**触发**：简历有"与业务方博弈""平衡规模与风险"
**好回答**：量化代价——算出放宽后新增人群的预期坏账与利润，给出"可承受的放宽幅度"；提替代方案（提价/降额/强催/灰度）；把争论从"要不要放"转成"以什么价格放"
**假好**：一味拒绝或一味服从；用"业务需要"当理由
**追问**：① 放宽的代价是多少 → ② 止损线怎么设 → ③ 你怎么说服业务方
